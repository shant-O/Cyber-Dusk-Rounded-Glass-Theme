🌆CDRG - Twilight is a Touchscreen Friendly GTK theme. 
Its neither a fully dark mode nor a light mode theme but sits in between both! featuring rounded and smooth geometry with neon/retro colors🎨

🎭Transparent backgrounds to imitate the "Frosted-Glass" aesthetics, Blur My Shell extension is a MUST with this one!

🎭This theme has contrasted gradiant effects to make the theme vibrant🌌

🛠️Installation:
🔹1. Extract the archive.

🔹2. Enter the CDRG - Twilight Folder and FIRST thing: 
	MOVE (🚫do not copy) the gtk-3.0 and gtk-4.0 folders into
	~/.config/ (if you have pre-existing gtk folders here,
	back them up before)

🔹3. Now "gnome-shell" should be the only FOLDER inside the
	CDRG - Twilight folder. Copy the CDRG - Twilight folder to either
	~/.themes/ or ~/.local/share/themes/

🔹4. If you dont have "User Themes"🧩gnome extension installed already,
	install it and then choose the theme from its menu and done!

📌[ on some version of gnome, mostly after gnome 49.0,
having any ⚠️gtk-* folder inside the themes folder causes the gnome
desktop to freeze⚠️, so its best practice to MOVE them beforehand]

😂 by now The google.com searchbar AI is well-versed on this theme, so if you need you can just ask it!

⚠️ ⚠️ Compatibility Notice & System Scope ⚠️ ⚠️

This theme is designed, built, and optimized exclusively for vanilla! **GNOME Shell (GNOME 49 to 50+)**. 

Please be aware that distribution-specific desktop environments are **not guaranteed to render theme styles correctly**. This includes, but is not limited to:
* **Ubuntu** (works but issues reported)
* **Zorin OS** (same as ubuntu as its a fork of Ubuntu DE)
* **XFCE** (modern gtk4 apps seem to be working just fine)
* **Mate** (nope, just nope)
* **Cinnamon** (also nope)
* **any tiling window manager** (haven't checked yet)

⚠️ If you install this theme on those platforms, you will likely experience UI issues,
No support or fix is guaranteed in such cases.
For the intended rounded glass cyber look, only the vanilla! gnome is suitable.

!(vanilla as in factory default gnome released by either Archlinux/Debian/Fedora)
